  <h3>Home Control 🏠</h3>
  <p>
    A self-hosted smart-home dashboard for a wall- or counter-mounted iPad, built on Home Assistant running in a VM on a home server.
    One glanceable view for rooms, lighting and climate, pet devices, a smart camera, utility energy usage, and a fitness page built from Apple Health data
    (weight trend, days trained, workouts) through a companion integration. Custom dark-academia / gothic design, iterated from mockups.
    Real data only: anything missing shows as unavailable, never as zero. Local-first and home-network only, with HTTPS through a reverse proxy.
  </p>
  <p>
    <b>Stack:</b> Home Assistant OS, Unraid, Lovelace dashboards generated by a Node build script, YAML template sensors, Node tooling.<br/>
    <b>Open source:</b> reported three bugs and a feature request upstream to the Halthy integration
    (<a href="https://github.com/Mosher23/Halthy/issues/8">#8</a>, <a href="https://github.com/Mosher23/Halthy/issues/9">#9</a>, <a href="https://github.com/Mosher23/Halthy/issues/10">#10</a>, <a href="https://github.com/Mosher23/Halthy/issues/11">#11</a>).
  </p>
